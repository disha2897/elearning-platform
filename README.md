# E-Learning Platform

A mini project built with Node.js, Express and Supabase (PostgreSQL).

Students can sign up, browse courses, enroll in them, and view lectures, tests and payments.

## How to run
1. Install Node.js from https://nodejs.org
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill in the Supabase URL and key (ask the team for them)
4. Run `npm start`
5. Open http://localhost:3000

## Tech
- Backend: Node.js + Express
- Database: Supabase (PostgreSQL)
- Frontend: HTML, CSS and JavaScript
